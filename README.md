# E-Commerce Frontend

A responsive e-commerce storefront built with HTML, CSS, and JavaScript.

## Features

- Product listing with 8+ products
- Search bar for product discovery
- Category filters
- Price sorting
- Shopping cart drawer
- Quantity controls
- Cart persistence using localStorage
- Checkout form with validation
- Responsive design for mobile and desktop
- Empty states and user feedback messages

## Project Structure

- `index.html` - Main storefront layout
- `styles.css` - Styling and responsive design
- `script.js` - Product data, filters, cart logic, and checkout validation

## Run Locally

1. Open the project folder in your browser, or
2. Start a local server from the project directory:

```bash
python -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```
